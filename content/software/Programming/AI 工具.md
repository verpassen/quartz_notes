# AI 工具

## 會議工具
- [Granola](https://www.granola.ai/)
AI會議筆記工具，自動記錄、轉錄會議內容並整理成重點筆記，節省會後整理時間。
- [Wispr Flow](https://wisprflow.ai/)
全應用程式適用的即時語音轉文字工具，讓您在任何程式中都能使用語音輸入。
- [Chrome + ViiTor ]
利用 chrome 開啟 teams 會議室，並且利用chrome 外掛 viitor 及時翻譯語音，比起原本內建的翻譯，可以複製下載翻譯後的文字(雙語)
