# openfoam - solver 

如果需要找到solver的資料夾可以在 terminal 輸入 
```bash
$FOAM_SOLVERS
# /usr/lib/openfoam/openfoam2406/applications/solvers
```

[solver 的類型](https://www.openfoam.com/documentation/user-guide/a-reference/a.1-standard-solvers) 

例如: 
icofoam 這個solver的敘述是
> Transient solver for incompressible, laminar flow of Newtonian fluids

所以它所適用的情境是

- transient
- incompressible
- laminar
- newtonian flow
